# Web Dev I - Lab Assignment 3
## Responsive Personal Portfolio Website

**Name:** Harsh Raj Jha
**Course:** B.Tech CSE (Core), KR Mangalam University

### Description
A one-page responsive portfolio website made with HTML and CSS. It uses Flexbox, CSS Grid, media queries, hover effects, transitions and animations.

### Files
- `index.html` - the web page
- `style.css` - the styling

### How to view responsive behavior
1. Open `index.html` in Chrome.
2. Press `F12`, then `Ctrl + Shift + M`.
3. Resize the screen and check the breakpoints below.

### Breakpoints tested
- **Mobile:** below 768px
- **Tablet:** 768px and above
- **Desktop:** 1024px and above
